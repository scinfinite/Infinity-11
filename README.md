## Architecture principles

- BYOK-first.
- Free-first.
- Open-source-first.
- Provider-independent.
- Multiple keys per provider.
- Local/self-hosted capable where feasible.
- No mandatory proprietary model.
- No mandatory paid AI gateway.
- E2B is an optional execution adapter.
- Supabase is an optional database adapter.
- Vercel is an optional deployment adapter.
- Central ALLOW / ASK / DENY security policy.
- Controlled execution for untrusted code.
- Evidence-first verification.
- UI does not duplicate backend orchestration.
- Competitor research provides patterns, not copied implementation.

## Phase completion rule

```text
inspect
→ reproduce / verify
→ diagnose root cause
→ implement
→ format
→ lint
→ typecheck
→ unit
→ integration
→ build
→ E2E / runtime
→ security
→ regression
→ UX / accessibility
→ documentation
→ final main CI
→ close
```

Never declare a phase complete from a mock, screenshot, successful happy-path command, or agent assertion alone.
